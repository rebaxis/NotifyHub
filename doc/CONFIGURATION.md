# Конфигурация

## Приоритет настроек
1. Переменные окружения (ENV)
2. Флаги командной строки
3. Значения по умолчанию

## Переменные окружения

### Основные настройки
| Переменная | Флаг | По умолчанию | Описание |
|-----------|------|--------------|----------|
| `PORT` | `-port` | `8080` | Порт HTTP сервера |
| `DATABASE_DSN` | `-db` | **обязательно** | Строка подключения PostgreSQL |
| `ADMIN_TOKEN` | `-admin-token` | **обязательно** | Токен администратора |
| `AGENT_REGISTRATION_TOKEN` | `-agent-registration-token` | **обязательно** | Токен регистрации агентов |
| `LOG_LEVEL` | `-log-level` | `info` | Уровень логов: debug, info, warn, error |

### HTTP таймауты
| Переменная | По умолчанию | Описание |
|-----------|--------------|----------|
| `HTTP_REQUEST_TIMEOUT` | `60s` | Макс. время обработки запроса |
| `HTTP_READ_TIMEOUT` | `15s` | Макс. время чтения запроса |
| `HTTP_WRITE_TIMEOUT` | `15s` | Макс. время записи ответа |
| `HTTP_IDLE_TIMEOUT` | `60s` | Макс. время простоя keep-alive |
| `HTTP_SHUTDOWN_TIMEOUT` | `10s` | Таймаут graceful shutdown |

### База данных
| Переменная | По умолчанию | Описание |
|-----------|--------------|----------|
| `DB_MAX_OPEN_CONNS` | `25` | Макс. открытых соединений |
| `DB_MAX_IDLE_CONNS` | `5` | Макс. простаивающих соединений |
| `DB_CONN_MAX_LIFETIME` | `5m` | Макс. время жизни соединения |
| `DB_PING_TIMEOUT` | `5s` | Таймаут проверки БД |
| `DB_MIGRATIONS_PATH` | `file://migrations` | Путь к миграциям |

### Health Check
| Переменная | По умолчанию | Описание |
|-----------|--------------|----------|
| `HEALTH_CHECK_TIMEOUT` | `2s` | Таймаут проверки готовности |

### Сервис очистки
| Переменная | По умолчанию | Описание |
|-----------|--------------|----------|
| `CLEANUP_INTERVAL` | `5m` | Интервал между циклами очистки |
| `NOTIFICATION_RETENTION_PERIOD` | `168h` (7 дней) | Срок хранения уведомлений |
| `AGENT_STALE_TIMEOUT` | `30m` | Таймаут неактивности агента |

### Безопасность
| Переменная | По умолчанию | Описание |
|-----------|--------------|----------|
| `BCRYPT_COST` | `10` | Стоимость bcrypt (4-31) |
| `SECRET_BYTE_LENGTH` | `32` | Длина секрета агента в байтах (16-64) |

## Рекомендации

**Разработка**: `BCRYPT_COST=4-6`, короткие таймауты  
**Продакшен**: `BCRYPT_COST=12-14`, `DB_MAX_OPEN_CONNS=100+`  
**Безопасность**: Использовать ENV, не коммитить токены, включить SSL (через Service Mesh)
